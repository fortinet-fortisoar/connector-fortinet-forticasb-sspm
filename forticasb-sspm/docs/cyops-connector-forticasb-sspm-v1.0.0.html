About the connector

FortiCASB-SSPM (SaaS Security Posture Management) is a cloud-based solution that provides visibility into security risks, user activities, identities, and data exposure across connected SaaS applications via API integration.

This document provides information about the FortiCASB-SSPM Connector, which facilitates automated interactions, with a FortiCASB-SSPM server using FortiSOAR™ playbooks. Add the FortiCASB-SSPM Connector as a step in FortiSOAR™ playbooks and perform automated operations with FortiCASB-SSPM.

Installing the connector

From FortiSOAR™ 5.0.0 onwards, use the Connector Store to install the connector. For the detailed procedure to install a connector, click here.
You can also use the following yum command as a root user to install connectors from an SSH session:

yum install cyops-connector-forticasb-sspm

Prerequisites to configuring the connector

  • You must have the URL of FortiCASB-SSPM server to which you will connect and perform automated operations and credentials to access that server.
  • The FortiSOAR™ server should have outbound connectivity to port 443 on the FortiCASB-SSPM server.

Included playbooks

The Sample - forticasb-sspm - 1.0.0 playbook collection comes bundled with the FortiCASB-SSPM connector. These playbooks contain steps using which you can perform all supported actions. You can see bundled playbooks in the Automation > Playbooks section in FortiSOARTM after importing the FortiCASB-SSPM connector.

  • Get Audit Log
  • Get Files
  • Get Identities
  • Get Risks
  • Get User Activities

Note: If you are planning to use any of the sample playbooks in your environment, ensure that you clone those playbooks and move them to a different collection, since the sample playbook collection gets deleted during connector upgrade and delete.
